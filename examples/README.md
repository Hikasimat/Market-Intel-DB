# Import Examples

This directory contains spreadsheet and CSV templates/examples used for importing data into MarketIntel DB.
- `prospect_import_4_companies.xlsx`: Example data with 4 companies.
- `prospect_import_blueprint.xlsx`: Blueprint for prospect import.
- `smart_prospect_import_blueprint.xlsx`: Blueprint for smart prospect import.
- `prospect_import_blueprint.csv`: CSV variant of the import blueprint.
